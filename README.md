# SerenitySpace

SerenitySpace is a mental wellness web application offering guided meditations, mood tracking, journaling, and access to online therapy. It provides a calming, easy-to-use space for emotional support anytime, anywhere.

## Features

- **Mood Tracking**: Smart insights to help users monitor their emotional health over time.
- **Journaling Prompts**: Daily prompts for self-reflection, clarity, and mental peace.
- **Online Therapy**: Access certified therapists anytime, anywhere for emotional support.
- **Guided Meditations**: Stress-relief and focus-enhancing sessions tailored to user needs.
- **Premier Services**: Personalized wellness plans, group meditation sessions, and exclusive therapy sessions.

## Pages

- **Home Page**: Overview of SerenitySpace and its features.
- **About Page**: Learn more about SerenitySpace's mission, vision, and core values.
- **Blog Page**: Articles and tips on mental wellness and mindfulness.
- **Contact Page**: Reach out to SerenitySpace for inquiries or support.
- **Payment Page**: Subscribe to premier services using credit card or PayPal.

## Technologies Used

- **HTML5**: For semantic structure.
- **CSS3**: For responsive and visually appealing design.
- **JavaScript**: For interactivity (e.g., "Read More" buttons, form validation).
- **GitHub Pages**: For deployment.
